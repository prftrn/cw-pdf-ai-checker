# 【GAS×Gemini AI】クラウドワークス案件PDF・自動AI格付けシステム

## ■ 開発の背景と目的
クラウドソーシングで副業や案件を探す際、膨大な募集案件の中から「自分のスキルに合わない地雷案件」や「規約違反のリスクがある案件」を1件ずつ手動で精査するのは非常に時間がかかります。
また、Webサイトからプログラムで直接データを集めるスクレイピング（自動データ収集技術）は、アカウント凍結（BAN）のリスクが伴います。

そこで、安全性に100%配慮し、手動で保存した「案件募集要項のPDF」をGoogleドライブに放り込むだけで、最新のAIが自動で内容を読み込み、独自の基準でS〜Cランクに格付けしてくれる「完全内製型のAI秘書システム」を開発しました。

## ■ システムの仕組み（運用フロー）
1. **案件のPDF化**: ユーザーが気になる案件を見つけたら、ブラウザの印刷機能で「PDF」として保存します。
2. **ドライブへ投函**: Googleドライブの「判定待ちフォルダ」へPDFをアップロードします。
3. **AI自動判定**: スプレッドシートの専用メニューから実行すると、プログラムが自動で起動します。
4. **結果の蓄積**: PDFから文字データをえぐり出し、Gemini AIに渡して査定。結果をスプレッドシートの「案件リスト」に瞬時に書き出します。
5. **フォルダの整理**: 読み終わったPDFは、重複処理を防ぐために「判定済みフォルダ」へ自動で移動します。

## ■ 技術スタック（使用した技術）
- **Google Apps Script (GAS)**: Googleのサービスを自動化するプログラミング言語。
- **Google Drive API (v3)**: Googleドライブを高度に操作するための外部連携機能。
- **Google ドキュメント OCR機能**: 画像やPDFの文字をデータとして自動認識・抽出する技術。
- **Gemini 2.5 Flash API**: 最新の超高速・高性能AIを外部から呼び出す窓口。

## ■ 実装における工夫・こだわり（アピールポイント）
1. **利用規約・安全性の徹底遵守**
   クラウドワークス側のサーバーに自動アクセスしない設計（PDFのローカル処理）を徹底し、アカウントの安全性を100%担保しました。
2. **超親切な「URL直接貼り付け」機能（UX向上）**
   プログラムの知識がないユーザーでも直感的に使えるよう、設定シートにフォルダの「URL」をそのまま貼り付けるだけで、プログラムが内部で自動的にフォルダID（固有の背番号）をくり抜いて認識する仕組みを自作しました。
3. **AIの回答フォーマット崩れ対策（堅牢性）**
   AIの返答が壊れてスプレッドシートへの書き込みが失敗するのを防ぐため、AIに対して「改行なしの1行のJSONデータ（プログラムが読みやすいデータ形式）のみで返却せよ」と厳格な指示（プロンプト）を設計し、文字コードを用いた独自のトリミング機能を搭載しました。
4. **エラーを自白する診断メーター（デバッグ機能）**
   通信エラー（404等）や混雑エラー（503等）が発生した際、処理が闇に葬られないよう、Google側から返ってきた生のエラーメッセージを画面中央にポップアップ表示して原因を突き止める「ドラレコ機能」を組み込みました。
